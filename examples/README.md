# Zyphor Integration Examples

This directory provides reference implementations and script adapters for integrating Zyphor into enterprise observability stacks.

## Available Examples
- `json_exporter.py`: Sample Python script consuming `zyphor --json`.
- `alert_webhook.py`: Webhook forwarder triggering alerts on health score drops.
- `dashboard.html`: Minimal dark-mode HTML interface visualizing telemetry.
- `monitor_daemon.sh`: Headless monitoring loop.
